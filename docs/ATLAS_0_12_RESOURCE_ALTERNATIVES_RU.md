# Atlas 0.12. Сравнение плановых ресурсных назначений

## Что получает пользователь

На экране «Плановые ресурсы» можно открыть «Сравнить варианты», выбрать существующую Work и один из уже заведённых ресурсов. Atlas показывает текущую и предполагаемую перегрузку по всему портфелю, дни вне указанного периода доступности и изменение загрузки обоих ресурсов.

Пользователь видит, сокращается ли общая перегрузка или лишь переносится на другой ресурс. Работу можно открыть в штатной форме и отдельно изменить ресурс. Сравнение ничего не применяет и не сохраняет.

## Источник расчётов

- `portfolioSchedule`: действующий общий прогноз сроков;
- `portfolioResources`: существующая общая модель плановой загрузки с учётом выбранных календарей;
- Временная проекция одной Work: меняется только ссылка на плановый ресурс в отдельной копии выбранной работы. Применение выполняется через штатный редактор Work и его обычную проверку данных.

Новый планировщик, Store, Core и формат `.iwxa` не создаются. Изменение планового ресурса само по себе не передвигает сроки CPM: ресурсное выравнивание пока не реализовано.

## Граница ответственности

Плановый ресурс в Atlas - не учётная запись сотрудника и не подтверждение доступности оборудования. Назначение показывает только заявленную мощность и привязку Work. Сотрудники, полномочия и корпоративные поручения принадлежат Admin Center и оригинальному T3. Предметное исполнение и проверяемые результаты остаются у соответствующего доменного продукта или Personal Agent.

## Приёмка

Проверить освобождение перегруженного ресурса, перенесённую на другой ресурс перегрузку, выход за период доступности, отсутствие расчётных дат, недопустимые назначения, отсутствие изменений Native Store и возврат в обычную форму Work. В Windows использовать настоящий `.iwxa`, Setup Core и окно 820×650.
