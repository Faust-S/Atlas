# IWXA Atlas 0.2.0 — выпуск Windows

Самостоятельное Windows-приложение Tauri 2 / WebView2 / Rust с локальными проектами, целями и работами, межпроектными зависимостями, CPM, Gantt/DAG, публичными GitHub-наблюдениями, историей фактов, решением человека и отдельным применением плановых изменений.

Хранение: `%LOCALAPPDATA%\\ru.iwxa.atlas\\atlas-store-v1`. Сохранение вручную (Ctrl+S). Для установки нужен Windows с WebView2 Runtime. Интернет не требуется для локальной работы; публичная синхронизация GitHub требует доступа к API.

Импорт: существующий JSON `atlas.project/1` из Atlas 0.1 → «Открыть JSON» → предпросмотр → подтвердить замену → «Сохранить». Резервная копия: кнопка «Резервная копия» → выбрать новое имя `.json`. История: «Версии на диске» → выбрать редакцию → восстановить, затем перечитать после перезапуска.

Отложены на 0.3: синхронизация устройств, корпоративные подключения, Admin Center/T3, агенты и расширенные инфраструктурные средства.

Релиз допускается только на финальном SHA с выполненной матрицей G01–G12. Проверенные commit, TREE, Windows workflow, SHA-256 и установщик должны указываться в опубликованной странице GitHub Release.
