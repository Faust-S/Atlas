## 2. Действительная архитектура

Самостоятельная Windows-программа: Tauri 2 + Rust + системный WebView2; React 19 + TypeScript. Действующее предметное ядро переиспользуется из `src/*.mjs`. Источник истины для Desktop — только Rust `atlas-store-v1`, с `head.json`, адресуемыми SHA-256 блоками, историей, поколениями, блокировкой, ручным `atlas_commit` и проверяемым readback. Файловый импорт/экспорт — через системный диалог. `desktop/src/ProjectVisuals.tsx` и `desktop/src/visual-layout.mjs` — интерфейсные проекции существующего CPM/DAG, не вторые алгоритмы.

Поддерживаются требования/факты/история/Git SHA, планы и последствия, human review, предложения, утверждения, отдельное применение корректировок, CPM, ресурсы, межпроектные зависимости, Gantt/DAG, поиск, масштабирование, фильтры, сортировка, сохранение и восстановление истории. Это реализованные функции, не автоматический release PASS каждого пользовательского сценария.

## 4. Текущий Windows-import HOLD и его причины

- [#41668641856](https://github.com/Faust-S/Atlas/actions/runs/41668641856): установленный lifecycle PASS, но UIA не увидел файловый диалог `#32770` — драйвер теста.
- [#41670827531](https://github.com/Faust-S/Atlas/actions/runs/41670827531): диалог найден (`ATLAS_IMPORT_PICKER_FOUND backend=uia class=#32770 title='Открыть архив Atlas JSON'`), предпросмотр достигнут, но тест не подтвердил сохранение импортированного портфеля: `ATLAS_INSTALLED_LEGACY_01_GUI_HOLD phase=save-imported-draft`. Диагностический снимок отсутствовал из-за неустановленного Pillow. **Нельзя утверждать ни loss of data, ни корректность GUI-импорта.**
- Кодовый коммит `6144c4ef6f3c5144be15a64bb45dbabbbf3e880a`, TREE `da9d485ca2e15722bad5f8e3766b519ab9bedb68`, добавил ожидание доступной/включённой кнопки, явные click-логи, диагностические сведения UIA и native head, Pillow и Python syntax gate.
- [Actions #41677382810](https://github.com/Faust-S/Atlas/actions/runs/41677382810) стартовал на этом SHA. **При публикации передачи итог ещё не зафиксирован**. В новом чате прочитать итоговый run/jobs/logs и скриншоты, прежде чем делать следующий коммит.

В случае следующего FAIL сравнить фактическую генерацию/редакцию `head.json`, список проектов, доступность кнопки, сообщение ошибки/статуса и последовательность кликов после предпросмотра. Отладить границу React `applyPendingImport` / `save`, не переписывать Rust-store без доказанного дефекта. `desktop/tests/installed-windows-import.py` читает store для независимой проверки, но никогда не записывает его напрямую.
