## 2. Зачем нужен продукт

Atlas — универсальное самостоятельное приложение управления личными, инженерными, исследовательскими и корпоративными проектами. Задача пользователя — видеть в одном пространстве:

- **Что должно быть:** цель, требования, обязательства, этапы, план работ и зависимости.
- **Что фактически известно:** наблюдения, происхождение, исходные GitHub SHA/даты, свежесть, противоречия и пробелы.
- **Что планируется и утверждено:** human review, заявки, сроки, ресурсы, решения, сценарии до/после, отдельное утверждение и применение.
- **Что меняется в портфеле:** CPM, critical path, межпроектный DAG и связанные риски.
- **Насколько достоверны данные:** заявления исполнителя/статус done/зелёный CI не являются независимой приёмкой результатов.

Atlas не исполняет задачи вместо человека или существующих Agent/Task Engine/Goose/Codex; не создаёт собственные корпоративные права или систему синхронизации. Admin Center и T3 **отложены** по решению владельца.

## 3. Версии и архитектура

### 0.1: зафиксированная веб-основа

Исходное `src/*.mjs` содержит нормализованную модель `atlas.project/1`, CPM, план/факт, историю, решения, публичные GitHub-наблюдения, ресурсы, сравнения и портфельные последствия. `src/storage.mjs` — IndexedDB для веб-версии 0.1, она **не исполняется как второй store в Desktop 0.2**. Оставить 0.1 неизменной.

### 0.2: самостоятельное Windows-приложение

- `desktop/src/main.tsx`: React 19 + TypeScript — реальный интерфейс проекта и портфеля.
- `desktop/src/ProjectVisuals.tsx`: календарный Gantt, поиск, масштабы, критический путь, интерактивный граф работ.
- `desktop/src/visual-layout.mjs`: только проекция существующего CPM; без нового планировщика.
- `src/editor.mjs`: общие именованные формы, `editorSpec` / `applyEditor`, переиспользованы как есть.
- `src/core.mjs`, `src/planning.mjs`, `src/portfolio-schedule.mjs`, `src/plan-review.mjs`, `src/plan-amendment.mjs`, `src/portfolio-resources.mjs`, `src/trace.mjs`, `src/public-refresh.mjs`: исходные предметные механизмы; desktop их **импортирует**, не копирует.
- `desktop/src-tauri/src/lib.rs`: Tauri 2/Rust; один authoritative native store в `app_local_data_dir()/atlas-store-v1`; `head.json`, неизменяемые блоки SHA-256, история, блокировка, проверки целостности, конфликты поколения; команды `atlas_open`, `atlas_commit`, `atlas_export_json`, `atlas_select_import`, `atlas_restore_previous`.
- `desktop/src-tauri/tauri.conf.json`: собственное окно Tauri/WebView2, NSIS, CSP. В release нет Vite-сервера; он нужен только во время разработки.
- `desktop/src/bootstrap.ts`: пользовательская диагностика загрузки; `AtlasRenderBoundary` в React.
- Явная команда сохранения (Ctrl+S), readback после `atlas_commit`, предупреждение о несохранённых правках; импорт/экспорт JSON через нативные диалоги. `.iwxa` Desktop-контракт ещё не реализован.
- Никаких второго Kernel, Host, Agent, Task Engine, Store, RBAC или конкурентного пакета графа.
