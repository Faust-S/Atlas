## 2. Продукт и архитектура

Atlas 0.2 — **самостоятельная локальная Windows-программа**, а не веб-сайт и не часть Agent по умолчанию. Tauri 2 + Rust + системный WebView2, React 19 + TypeScript. Подключение к Personal Agent в перспективе должно импортировать данные в разрешённые Core-интерфейсы по отдельному проектному решению, а не запускать второй store. Версия 0.1 зафиксирована в `release/0.1`; `main` не изменять.

Действующие предметные алгоритмы импортируются из `src/*.mjs`: план/факт, требования, факты и их источники, критический путь CPM, межпроектные зависимости, human review, предложение/утверждение/применение изменения, сценарии последствий и ресурсы. `desktop/src/main.tsx` — рабочий интерфейс; `desktop/src/ProjectVisuals.tsx` и `desktop/src/visual-layout.mjs` — **проекции**, не новый планировщик. `src/editor.mjs` содержит общие именованные формы `editorSpec/applyEditor`. Единственный authoritative Desktop store — `desktop/src-tauri/src/lib.rs`, `atlas-store-v1` с `head.json`, SHA-256 блоками, историей, поколениями, блокировкой, восстановлением и ручным сохранением с readback. Импорт/экспорт JSON через нативные диалоги.

Нельзя создавать второй Agent, Task Engine, Host, Kernel, систему прав, конкурентное хранилище или дублирующий графовый/CPM движок. Не трогать приватный `Faust-S/IWXA-Atlas`. Admin Center и T3 **отложены**. GitHub Actions использовать только экономно. Codex — для операций, которых самостоятельно выполнить нельзя, и независимой финальной приёмки. Не использовать UIA/CDP/Chromium для установленного GUI вместо настоящего Win32/WebView2.

## 2. Зачем нужен продукт

Atlas — универсальное самостоятельное приложение управления личными, инженерными, исследовательскими и корпоративными проектами. Задача пользователя — видеть в одном пространстве:

- **Что должно быть:** цель, требования, обязательства, этапы, план работ и зависимости.
- **Что фактически известно:** наблюдения, происхождение, исходные GitHub SHA/даты, свежесть, противоречия и пробелы.
- **Что планируется и утверждено:** human review, заявки, сроки, ресурсы, решения, сценарии до/после, отдельное утверждение и применение.
- **Что меняется в портфеле:** CPM, critical path, межпроектный DAG и связанные риски.
- **Насколько достоверны данные:** заявления исполнителя/статус done/зелёный CI не являются независимой приёмкой результатов.

Atlas не исполняет задачи вместо человека или существующих Agent/Task Engine/Goose/Codex; не создаёт собственные корпоративные права или систему синхронизации. Admin Center и T3 **отложены** по решению владельца.
