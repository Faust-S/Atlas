# Atlas 0.12. План и исполнение без дублирования продуктов IWXA

## Роль Atlas

Atlas строит, сравнивает и изменяет **план**: Project, Work, зависимости, сроки, календари, плановую загрузку ресурсов, контрольные редакции, наблюдения источников и последствия решений.

Atlas самостоятельно работает с проектами в установленной Windows-программе. Для создания проекта, просмотра Ганта, изменения Work, сравнения календарных сценариев и сохранения `.iwxa` не нужны Admin Center, Personal Agent или предметный домен.

## Границы продуктов

| Предмет решения | Владелец | Что видит Atlas |
| --- | --- | --- |
| Сроки, порядок и связи Work | Atlas | Расчёт, отклонение, предлагаемый вариант |
| Организации, сотрудники, корпоративные права | Admin Center и исходный T3 | Ссылка на подтверждённый источник, не копия кадровой базы |
| Выполнение разрешённых Task, подготовка Result | Personal Agent и исходный T3 | Ссылка на конкретные Task и Result по действующим правилам |
| Производство, поставка, торговля, услуги, лечение и другое предметное исполнение | Соответствующий доменный продукт | Связанный этап, наблюдение, полученный подтверждённый результат |
| Workspace, подписанный обмен, события и жизненный цикл | Оригинальные T3/T2 | Проекция только разрешённых сведений |

Atlas **не** создаёт второй Task Engine, IAM, Core, Store, Graph или формат `.iwxa`. В нём не появляются собственная диспетчерская цеха, бухгалтерия, управление персоналом или приёмка Result вместо его владельца.

## Первая функция 0.12: плановая готовность Work

Используются действующие `portfolioSchedule`, `scheduleProject` и `portfolioResources`. Новая проекция только читает существующий снимок и сообщает:

- какие Work не имеют незавершённых предшественников **в записанном плане**;
- какие Work ожидают предыдущие Work или связанные проекты;
- где не определена дата, заявлена блокировка или требуется проверка общей загрузки планового ресурса;
- какие Work пользователь отметил выполняемыми или завершёнными.

**Нет препятствий в записанном плане** не означает, что поставка пришла, сотрудник доступен, Task выполнена, Result принят или заказ закрыт. Atlas не выводит такие решения из даты CPM, совпадения имени или пользовательской отметки `done`.

Результат отображается в действующем разделе «Состав проекта» внутри раскрываемого блока. Пользователь может открыть конкретную Work штатной командой «Проверить работу»; новые экраны или параллельное хранилище не создаются. Расчёт не записывается в Native Store.

## Следующие предметные задачи

1. Ресурсные альтернативы, рассчитанные поверх действующей календарной модели. Не новый планировщик.
2. Понятные причины недостижимости сроков с переходами к текущим Work и ресурсам.
3. Сравнение вариантов и фиксация **выбранного человеком изменения плана** в действующей истории.
4. Точные переходы по WorkRef к Admin Center или Agent, когда они установлены; отсутствие внешних программ не блокирует Atlas.
5. Отображение результатов от исходных владельцев через существующий T3. Atlas не заменяет Human Review.

Приёмка должна проверять самостоятельный сценарий, межпроектные связи, ресурсы, 820×650, неизменность Native Store после предпросмотра, независимый импорт `.iwxa` и холодное восстановление.
