# Atlas 0.7. Связь существующей работы с каталогом

Пользователь выбирает наблюдаемый каталог и явно указывает уже
существующую работу. Применение формы меняет её привязку к источнику
и редакции в черновике. Сохранение проекта выполняется отдельно.

Устаревшая редакция источника или отсутствующий каталог отклоняются.
Работы и зависимости автоматически не создаются. Использованы
действующие редактор, проектная модель и формат обмена .iwxa.

## Сквозная Windows-проверка

Отдельный Windows-сценарий использует уже установленный Atlas после
проверки большого проекта: у существующей работы меняется только путь
к наблюдаемому каталогу. Форма должна открыться физическим нажатием,
выбор работы не должен записывать данные до подтверждения, а после
«Сохранить» и перезапуска весь проект должен совпадать с ожидаемым.

## Удаление неверной привязки

Из обычного редактора связанной работы можно явно выбрать
«Убрать привязку». Atlas удаляет связь с источником, каталогом
и записанной редакцией. Сама работа, её этап, сроки, ресурсы,
требования и зависимости сохраняются. Действие меняет черновик;
на диск оно попадает только после «Сохранить».

Редактор не предлагает удаление для работы без источника.
Некорректный выбор и попытка записать неполную привязку отклоняются.
После удаления можно связать эту же работу с другим наблюдаемым каталогом,
не создавая дубликат. Нативная Windows-проверка проходит через
действующий редактор и отдельное сохранение с повторным запуском.


## Поиск при большом количестве работ

Форма «Связать работу» предлагает поиск по названию и этапу.
Даже в проекте с 1200 и более работами поиск охватывает все записи,
а интерфейс показывает первые 12 совпадений. Видно количество найденных
работ. Ввод поискового текста ничего не меняет: работу необходимо
выбрать отдельно. Уже сделанный выбор сохраняется при изменении запроса.
Совпадающие названия дополнены этапом, при полном совпадении
различаются порядковым номером в проекте. Используется прежний
редактор, проектная модель и формат .iwxa.

Для проверки добавлены предметные Node-тесты и Windows-сценарий
выбора работы из конца большого проекта с отдельным сохранением,
перезапуском и точной проверкой прочитанных данных.


## Компактный редактор Windows

При проверке установленного Atlas на большом проекте 12 ноября выявлена
недоступность команды применения в длинной форме работы, где есть
привязка к исходникам. Компоновка редактора исправлена: поля прокручиваются
внутри отдельной области, а «Отмена» и «Применить к черновику»
остаются внизу панели и не уходят за границы окна. Сохранение
проекта по-прежнему требует отдельного действия.

Проверка готовности этого исправления: штатная Windows-квалификация
большого проекта, затем снятие ошибочной привязки и поиск существующей
работы в том же установленном приложении. До такого результата
новую компоновку нельзя считать принятой.
