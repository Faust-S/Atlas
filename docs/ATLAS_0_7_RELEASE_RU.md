# IWXA Atlas 0.7.0 — контроль стабильного выпуска

## Предмет версии

Atlas помогает подключить, увидеть и вести проект, включая большие
портфели. В обзоре есть переход к работам с нарушенным контрольным
сроком и к критической цепочке. Перед изменением связи показывается
пересчёт без записи. Изменение и сохранение разделены.

Поиск работает по проектам, работам, этапам и каталогам. Навигация
между обзором, таблицей и графиком остаётся доступной при длинных
списках. Существующие источники, планы и история остаются в
штатном Store; обмен производится через .iwxa. Ответственность за
изменения остаётся у пользователя.

## Условия приёмки

Релиз публикуется только при успешном завершении на одном SHA:

1. Node-тестов и TypeScript/Vite;
2. сборки Windows x64 и штатной установки IWXA Setup Core;
3. нативных тестов локального Store и холодного перезапуска;
4. прямого редактирования критической связи с прогнозом и явным сохранением;
5. испытания проекта свыше 1200 работ, поиска по портфелю,
   создания и исправления работ, источников и связей;
6. проекта без GitHub и реальной совместимости .iwxa с Center;
7. проверки SHA-256 финального EXE-установщика.

Тег v0.7.0 и файлы IWXA-Atlas-0.7.0-Setup.exe и .sha256 создаются
в рамках того же прошедшего Windows workflow. Пока статус workflow
не SUCCESS и ссылка релиза не опубликована, выпуск не считается
принятым. Ветка release/0.6 и релиз v0.6.0 не изменяются.
