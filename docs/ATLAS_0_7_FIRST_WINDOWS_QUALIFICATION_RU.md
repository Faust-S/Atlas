# Atlas 0.7. Первая Windows-квалификация

Дата: 12 ноября 2026 года.
Ветка: `work/2026-11-12-atlas-0-7`.

## Проверяемый пользовательский маршрут

Пользователь создаёт обычный проект, в котором нет GitHub и ещё
не записаны источники. В обзоре видит существующий блок «Состав
проекта» и действие «Подключить источник». Это действие
переводит в действующий раздел «Источники проекта».

Нажатие и возврат не добавляют источник, не создают работу,
не выдают разрешений и не сохраняют проект. Только явное
подтверждение в редакторе и нажатие «Сохранить» меняют данные.

## Фактические критерии

- Собранная программа устанавливается через IWXA Setup Core.
- Отображается и открывается обычный проект без GitHub.
- «Подключить источник» видно и физически доступно в Windows.
- Существующий экран источников открывается из обзора.
- Возврат показывает ту же схему проекта.
- SHA и сохранённое состояние до и после навигации совпадают.
- Регрессия Atlas 0.6: большой проект, контроль срока, `.iwxa`,
  восстановление после перезапуска и отсутствие непрошеных записей.

Источник проверки: действующий Windows-сценарий
`desktop/tests/installed-atlas06-universal.py` с новой отметкой
`ATLAS07_UNIVERSAL_SOURCE_ENTRY_PASS`. Отметка означает успех
только после прохождения установленного интерфейса.
