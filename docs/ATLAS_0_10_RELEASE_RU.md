## Реализованный продукт

Работы с календарной или рабочей длительностью и точной редакцией календаря, именованные организационные календари, исключения и дополнительные рабочие даты, единый календарный CPM, последствия межпроектных связей, пояснения критических зависимостей, учёт занятости ресурсов по действительным датам, Гант и таблица Work, сравнение рабочих календарей без неявной записи в Store.

Не создаются новый Core/Store/Router или другой формат: используются оригинальные T3, Native Store, `.iwxa` и IWXA Setup Core.

## Публикация

Стабильный `v0.10.0` публикуется отдельным контролируемым workflow `.github/workflows/atlas-0-10-publish.yml`. Workflow проверяет SUCCESS указанного Windows-прогона и его точный SHA, скачивает уже принятый Windows-EXE без пересборки, проверяет SHA-256 и создаёт GitHub Release только при отсутствии прежнего тега и релиза.

Публикация считается завершённой только после SUCCESS workflow и появления тега `v0.10.0` и обоих файлов на GitHub Release.

## Границы

- Нет автоматического выравнивания ресурсов и удостоверения доступности сотрудников.
- Прогноз не подтверждает фактическое исполнение или принятие Result и не изменяет исходный план без пользователя.
- Нет Authenticode-подписи издателя; SHA-256 проверяет целостность, но не является такой подписью.
- Совместимость редактирования архивов в установленной Atlas 0.8 не включена в приёмку: там нет рабочих пользовательских данных.
- Лицензирование организации остаётся за IWXA Admin Center; отдельной системы лицензирования Atlas здесь не вводится.
