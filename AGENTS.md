# IWXA: действующие правила разработки


## GitHub Actions: осознанный одноразовый автоматический запуск (25.11.2026)

Действующее решение владельца для всех разработчиков и ИИ: [единый порядок IWXA](https://github.com/Faust-S/iwxa/blob/knowledge/2026-10-02-system-atlas/knowledge/system/AI_CONTEXT_POLICY_RU.md#github-actions-осознанный-одноразовый-автоматический-запуск-решение-владельца-25112026). Обычные изменения кода, документации, workflow, push/PR и расписания не запускают Actions. Сначала выполнить доступные самостоятельные проверки. Только при действительно необходимой недоступной операции или завершённом кандидате агент сам инициирует один прогон в согласованном публичном CI-контуре через workflow_dispatch API либо отдельную ветку ci/once/<workflow-id>/<prepared-sha> и единственный новый request-файл по центральному контракту. Проверить очередь, точные SHA, отсутствие дублей; не повторять успешное без изменения входов, не отменять полезный текущий прогон. Это заменяет исключительно ручной режим; Actions в закрытых репозиториях запрещены, существующие разрешения и критерии приёмки неизменны. Архивные ветки и зафиксированные кандидаты не переписывать ради обновления инструкции.
